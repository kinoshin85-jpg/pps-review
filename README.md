Aritzia PPS Review Record web app for Hansoll Vina.

### Usage
Open the deployed URL on any mobile browser (Safari / Chrome).

### Deploy to GitHub Pages
1. Create a new repository on GitHub named `pps-review`
2. Upload all files in this folder
3. Go to Settings → Pages → Source: main branch / root
4. Access at: `https://[your-username].github.io/pps-review/`
